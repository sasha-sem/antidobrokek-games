# Разработка frontend

Frontend запускается через Vite с hot module replacement: после сохранения файла в `frontend/src` открытая страница обновляется автоматически. Пересобирать Docker-образ `quiz-web` при разработке не нужно.

## Первый запуск

Нужны Docker Compose и Node.js 22.22+ (либо 24.15+). Из корня репозитория:

```bash
cp .env.example .env
cd frontend
npm install
cd ..
```

В `.env` замените `HOST_SECRET` и `ADMIN_TOKEN` на разные значения длиной не менее 16 символов. Остальные локальные настройки можно оставить без изменений.

## Ежедневный запуск

Откройте два терминала в корне репозитория.

В первом запустите backend и раздачу видео одной командой:

```bash
make backend-dev
```

Команда выполняет миграции, запускает FastAPI на `http://127.0.0.1:8000` и текущие видео на `http://127.0.0.1:8080`.

Во втором запустите frontend:

```bash
make frontend-dev
```

Откройте сайт:

```text
http://localhost:5173
```

Vite проксирует `/api` и `/ws` в FastAPI, а `/media` — в локальную раздачу видео. Ссылки на комнаты, созданные в dev-режиме, также используют порт `5173`.

## Как редактировать

Основной код находится в `frontend/src`:

- `pages/` — страницы и игровой сценарий;
- `components/` — переиспользуемые компоненты;
- `hooks/` — WebSocket и синхронное воспроизведение;
- `*.module.css` — стили соответствующих страниц и компонентов.

Сохраните изменённый `.tsx` или `.css` файл — Vite применит изменение в браузере без ручной сборки. Если менялась логика подключения или состояние из `localStorage`, иногда полезно обновить страницу через `Ctrl+Shift+R`.

Для остановки нажмите `Ctrl+C` в обоих терминалах. Если backend был оставлен в фоне, остановите его командой:

```bash
make backend-dev-stop
```

## Проверка перед production

```bash
cd frontend
npm run lint
npm test
npm run build
```

Production по-прежнему использует собранный React внутри Caddy и запускается через обычный `docker compose up -d`.
